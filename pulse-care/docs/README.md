//SYSTEM PURPOSE:

Pulse care is a java program that will be used in hospitals by medicalpractitioners and staff to coordinate hospial activities more so data entry and recording shifting from flay based methods of storage to relational. It will also facilitate communication betwenn various departments in the hospitals.

//USER-ROLES:

***ADMIN:
        =>MANAGES USERS IN THE SYSTEM.
        =>VIEWS SYSTEM REPORTS.
        =>HAS COMPLETE ACCESS TO ENTIRE SYSTEM.
***DOCTOR:
        =>ACT AS A SOURCE FOR THE EXPERT SYSTEM
        =>TREAT AND RECORD, VIEW EXISTIING PATIENT RECORDS.
        =>CONSULT EXPERT SYSTEM AS ASSISTANT.
***RECEPTIONIST:
        =>USE THE SYSTEM TO HANDLE BILLING AND RECEIPTS.
        =>USE THE SYSTEM TO ROUTE PATIENTS TO RESPECTIVE DEPATMMENTS.
        =>BOOK PATIENT APPOINTMENTS.
***PATIENT:
        =>BOOK APPOINTMENTS.
        =>CONSULT EXPERT SYSTEM IF DOCTOR UNAVAILABLE.
***NURSE:
        =>VIEW PATIENT RECORDS, AND PROVIDE TIMELY AND PRECISE UPDATES.

//MODULES:
The system consists of the following modules:

        ***AUTHENTICATION MODULE:
            =>This module will handle user authentication, logging and routing to prevent unauthorised access and intrusion into the system, it is one of the core features of the system.

        ***DATA ENTRY MODULE:
            =>This module handles all data input into the system.

        ***EXPERT SYSTEM
            =>This module contains databases and an expert system that will emulate a doctor and their experstise that is used hand in hand by doctors or patients when the need arises.

        ***PAYMENT MODULE
            =>This module handles all transactional operations mae and handled within the system through apis.

        ***REPORTS MODULE
            =>This module handles report creation, storage and presentation.
